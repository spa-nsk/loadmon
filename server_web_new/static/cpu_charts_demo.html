Заметки по сравнению
  • Chart.js: легче по весу, проще базовая настройка, для zoom/pan нужен отдельный плагин (chartjs-plugin-zoom).
  • ApexCharts: zoom/pan, экспорт в PNG/SVG и toolbar работают "из коробки"; выглядит более законченным виджетом без доп. плагинов.
  • Обе библиотеки на 1440 точках работают плавно; для потоковых realtime-обновлений (раз в 1 мин) можно просто добавлять новую точку и убирать первую (метод update() / updateSeries()).
