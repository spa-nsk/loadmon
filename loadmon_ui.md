# Описание пользовательского интерфейса loadmon

**loadmon** (Мониторинг утилизации ресурсов) — веб-приложение для мониторинга загрузки виртуальной инфраструктуры VMware vSphere, просмотра конфигураций серверов HPE OneView и ведения справочников учёта серверов/ВМ/кластеров.

Стек UI: **Beego** (шаблоны `.tpl`), **Bootstrap 5.3**, общие стили **`/static/css/loadmon.css`**, графики **ApexCharts**, экспорт PDF через **jsPDF**.

---

## 1. Общая компоновка экрана

Все основные страницы (кроме входа и служебных) используют макет из `header.tpl` + `footer.tpl`:

| Зона | Расположение | Назначение |
|------|--------------|------------|
| **Боковое меню** | Слева, фиксированная панель ~280 px | Навигация по разделам, имя пользователя, переключатель темы |
| **Рабочая область** | Справа, прокручиваемая | Заголовок страницы, фильтры, таблицы, формы, графики |
| **Flash-сообщения** | Вверху контента | Ошибки (`error`) и уведомления (`notice`) после операций |

**Тема оформления:** светлая / тёмная (кнопка внизу бокового меню, состояние в `localStorage`).

**Типовые элементы интерфейса** (классы из `loadmon.css`):

- **Панель фильтра** — закрепляется вверху при прокрутке; на части страниц можно отключить чекбоксом «Закреплять фильтр».
- **Таблица** — «классический» вид со sticky-заголовком; строки часто поддерживают **контекстное меню** (ПКМ).
- **Пагинация** — блок «Показано X–Y из Z», выбор размера страницы (50 / 100 / 200).
- **Экспорт** — кнопки «Экспорт в XLSX» (и иногда CSV) выгружают **весь** отфильтрованный набор, а не только текущую страницу.
- **Индикатор питания** — цветной LED у серверов (On / Off / Unknown и т.д.).

## 2. Аутентификация и права доступа

| Уровень (`Priv`) | Возможности |
|------------------|-------------|
| **0** | Просмотр данных VMware и OneView, справочников |
| **1** | + редактирование записей справочника |
| **3** | + раздел «Администрирование» (журнал действий), остановка сервиса |

**Маршруты без сессии** перенаправляют на `/user/login/...` с сохранением URL возврата.

| Страница | URL | Назначение |
|----------|-----|------------|
| Вход | `/user/login/:back` | Авторизация |
| Выход | `/user/logout` | Завершение сессии |
| Регистрация | `/user/register` | Новый пользователь |
| Подтверждение e-mail | `/user/verify/:uuid` | Активация учётной записи |
| Профиль | `/user/profile` | Изменение данных пользователя |
| Забыли пароль | `/user/forgot` | Запрос сброса |
| Сброс пароля | `/user/reset/:uuid` | Установка нового пароля |
| SSO | `/sso` | Вход через SSO |

## 3. Структура бокового меню

Меню видно только **авторизованным** пользователям (`InSession`).

### 3.1. Общие
- **Выйти** / **Авторизоваться**

### 3.2. Данные из VMware
| Пункт меню | URL | Описание |
|------------|-----|----------|
| Загрузка виртуальных машин с 00:00 | `/sprsrv/vm/all/all/all/all` | Список ВМ с метриками CPU/Mem/Disk/Net за текущие сутки |
| Список кластеров | `/sprsrv/listclusterview` | Справочный список кластеров vSphere с фильтрами и экспортом XLSX |
| Загрузка кластеров и хостов с 00:00 | `/sprsrv/cluster/all/all/all` | Текущая загрузка кластеров/хостов/ВМ (live vSphere через gRPC) |
| Загрузка кластеров и хостов за период (по данным БД) | `/sprsrv/clusterperioddb` | Агрегированные метрики за выбранный период из таблиц `cluster_record` / `host_record` / `vm_record` |

### 3.3. Данные из HP One View
| Пункт меню | URL | Описание |
|------------|-----|----------|
| Список серверов из HP One View | `/sprsrv/hwviewlist` | Таблица серверного железа с фильтрами по питанию, статусу, модели |
| Конфигурация сервера по серийному номеру | `/sprsrv/srvhwviewbysn/:SN` | Детальная карточка сервера OneView (в меню — заглушка SN `000000`) |

### 3.4. Справочники
| Пункт меню | URL | Описание |
|------------|-----|----------|
| Справочник серверов | `/sprsrv/view2/all/0` | Основной CMDB: физические серверы, гипервизоры, ВМ — учёт, размещение, биллинг |
| Конфигурации серверов | `/sprsrv/hwconflist/0` | Справочник `ServerHardware`: модели CPU/RAM/дисков, статус, размещение |

### 3.5. Администрирование (только Priv == 3)
| Пункт меню | URL | Описание |
|------------|-----|----------|
| Журнал действий пользователей | `/admin/userlog` | Просмотр `userlog`, фильтр по типу операции, пагинация, экспорт XLSX |

## 4. Раздел VMware (/sprsrv)

### 4.1. Список виртуальных машин — `/sprsrv/vm/:Vcenter/:Datacenter/:Cluster/:VM`

**Шаблон:** `vmlist.tpl`

**Фильтры:** vCenter, датацентр, кластер, имя ВМ (каскадные выпадающие списки; `all` — без ограничения).

**Таблица:** имя ВМ, vCenter, кластер, хост, CPU/Mem/Disk/Net (среднее/макс./мин.), теги, ссылки на детализацию.

**Действия:**
- переход к **графикам за день** — `/sprsrv/vmperfday/...`
- переход к **графикам за период** (из БД) — `/sprsrv/vmperfperiod/...`
- переход к записи справочника — `/sprsrv/updatebase/...`
- **экспорт XLSX** всего отфильтрованного списка

---

### 4.2. Список кластеров — `/sprsrv/listclusterview`

**Шаблон:** `clusterlist.tpl`

**Фильтры:** vCenter, датацентр (POST-форма «Просмотр»).

**Колонки:** vCenter, DC, имя кластера, число хостов/ВМ, ресурсы; дополнительно поля из справочника `ClusterSprRecords` (тип среды, статус, примечание).

**Действия:** ссылка на просмотр кластера `/sprsrv/cluster/...`, экспорт XLSX.

---

### 4.3. Загрузка кластера (live) — `/sprsrv/cluster/:Vcenter/:Datacenter/:Cluster`

**Шаблон:** `cluster.tpl`

**Источник данных:** текущее состояние vSphere в памяти (gRPC `metrics_grpc`).

**Фильтры:** vCenter, датацентр, кластер; опционально закрепление панели фильтра.

**Содержимое:**
- сводка по кластеру (CPU, память, datastore, агрегированные метрики);
- таблица **хостов** с метриками и ссылками на конфигурацию;
- таблица **виртуальных машин** кластера;
- раскрываемые блоки datastore.

**Ссылки:** графики кластера за день/период, карточки HW по SN/имени.

---

### 4.4. Загрузка кластера за период (БД) — `/sprsrv/clusterperioddb`

**Шаблон:** `clusterperioddb.tpl`

**Источник данных:** PostgreSQL (`cluster_record`, `host_record`, `vm_record`).

**Фильтры:** vCenter, датацентр, кластер, **дата начала** и **дата окончания** периода.

**Метрики:** для каждого кластера/хоста/ВМ — max/avg/min CPU, Mem, Disk, Net за период (агрегация по суточным записям).

---

### 4.5. Графики метрик

| Страница | URL | Данные | Экспорт |
|----------|-----|--------|---------|
| ВМ за день | `/sprsrv/vmperfday/...` | Live VMPerf | PDF |
| ВМ за период | `/sprsrv/vmperfperiod/...` | VMRecord из БД | PDF |
| Кластер за день | `/sprsrv/clusterperfday/...` | Live CLPerf | PDF |
| Кластер за период | `/sprsrv/clusterperfperiod/...` | ClusterRecord из БД | PDF |

**UI графиков:** карточки ApexCharts (CPU, память, диск, сеть), кнопка «Сохранить графики в PDF» (`jspdf` + `pdf-export.js`).

---

## 5. Раздел HP OneView (/sprsrv)

### 5.1. Список серверов — `/sprsrv/hwviewlist`

**Шаблон:** `hwviewlist.tpl`

**Фильтры:** состояние питания, статус эксплуатации, модель, текстовый поиск по имени/SN.

**Таблица:** имя, SN, модель, питание (LED), статус, расположение (DC/стойка/U), ссылка на карточку `/sprsrv/srvhwviewbysn/:SN`.

**Экспорт:** XLSX.

---

### 5.2. Карточка сервера OneView — `/sprsrv/srvhwviewbysn/:SN`

**Шаблон:** `srvhwviewbysn.tpl`

**Содержимое:** процессоры, память, диски, сетевые адаптеры, прошивки, размещение в стойке, состояние iLO; данные через gRPC из OneView.

---

## 6. Справочники CMDB (/sprsrv)

### 6.1. Справочник серверов — `/sprsrv/view2/:mode/:id`

**Шаблон:** `view2.tpl` (эталон UI-стиля проекта)

**Режимы (`mode`):** `all`, `server`, `vm`, `hypervisor` и др. — фильтрация типа записи.

**Фильтры:** много полей (статус, тип среды, vCenter, кластер, биллинг, текстовый поиск `#myInput`).

**Таблица:** учётные поля `ServerSprRecords` — имя, FQDN, тип, статус, размещение, метрики, биллинг.

**Контекстное меню строки (ПКМ):**
- открыть карточку редактирования;
- конфигурация сервера (HW);
- графики метрик;
- добавить запись.

**Пагинация:** page / pagesize; POST-форма `Update`.

---

### 6.2. Добавление записи — `/sprsrv/addserver/:backmode/:name`

**Шаблон:** `updatebase.tpl` (режим `.IsNew`)

Форма создания новой записи в справочнике (те же поля, что и редактирование).

---

### 6.3. Редактирование записи — `/sprsrv/updatebase/:backmode/:id`

**Шаблон:** `updatebase.tpl`

**Поля:** имя, FQDN, тип (физ./ВМ/гипервизор), статус, vCenter/кластер/хост, биллинг, примечания, связь с HW/VM.

**Связанные переходы:**
- по имени ВМ — `/sprsrv/vmeditbyname/:Name`
- групповое редактирование выбранных — `/sprsrv/updateselectedbase/:selected`

---

### 6.4. Конфигурации серверов (ServerHardware)

| Страница | URL | Назначение |
|----------|-----|------------|
| Список | `/sprsrv/hwconflist/:id` | Фильтр + таблица конфигураций |
| Карточка | `/sprsrv/hwconfedit/:id` | Просмотр/редактирование одной записи |
| По SN | `/sprsrv/hwconfeditbysn/:SN` | Редirect на карточку по серийному номеру |
| По имени | `/sprsrv/hwconfeditbyname/:Name` | Redirect через ServerSprRecords |
| Групповое | `/sprsrv/hwconfbulkedit` | Массовое изменение статуса/размещения |

**Шаблоны:** `hwconflist.tpl`, `hwconfedit.tpl`, `hwconfbulkedit.tpl`.

---

## 7. Администрирование

### 7.1. Журнал действий — `/admin/userlog`

**Шаблон:** `admin/userlog.tpl`

**Доступ:** только `Priv == 3`.

**Фильтр:** тип операции (авторизация, чтение справочника, экспорт, API и т.д.).

**Таблица:** Id, пользователь, время входа, время операции, тип, URL запроса.

**Действия:** экспорт XLSX (весь отфильтрованный журнал), закрепляемая панель фильтра.

Типы операций задаются константами `LogType*` в `controllers/userlog.go` (1–13).

## 8. Прочие страницы

| URL | Назначение |
|-----|------------|
| `/` | Домашняя (минимальная заглушка) |
| `/filter` | Фильтр отчётов (legacy) |
| `/details/:Mode/:ServerName` | Детали сервера (legacy) |
| `/notice` | Страница flash-уведомления |
| `/api/:json` | JSON API (поиск серверов и т.п.) |

**Служебные (не для конечных пользователей):** `/metrics` (Prometheus), `/debug/pprof/*`, `POST /shutdown`.

---

## 9. Журналирование действий в UI

При обращении к большинству маршрутов вызывается `RegisterRequest()` — в таблицу `userlog` пишется тип операции и URL. Это позволяет аудировать просмотры справочников, экспорты и изменения данных.

---

## 10. Карта навигации (упрощённо)

```
loadmon
├── Авторизация (/user/*)
├── VMware
│   ├── VM list → VM perf (day/period)
│   ├── Cluster list → Cluster view → Cluster perf (day/period)
│   └── Cluster period DB
├── OneView
│   ├── HW list → HW card by SN
│   └── (ссылки из cluster/view2)
├── Справочники
│   ├── view2 (servers) → updatebase / addserver
│   └── hwconflist → hwconfedit / bulkedit
└── Admin (Priv=3)
    └── userlog
```
